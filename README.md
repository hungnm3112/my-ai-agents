# My AI Agents

Bộ quy chuẩn, quy tắc thiết kế kiến trúc và triển khai dự án dành cho AI Agents.

## Cấu trúc thư mục

- `.agents/rules/`: Hệ thống các quy tắc và hướng dẫn Agent.
  - `1-core/`: Quy tắc cốt lõi (Workflow, Tech Stack, Naming, TypeScript, Git Commit).
  - `2-analysis/`: Phương pháp luận Systems Thinking, khảo sát bài toán, bóc tách Actor, DFD Level 0, FDD & RBAC.
  - `3-database/`: Thiết kế CSDL, Data Mapping, Conventions, Enterprise Patterns, Mongoose.
  - `4-api/`: Chuẩn RESTful API, Error Codes, Request/Response Payload, Docs.
  - `5-backend/`: Kiến trúc NestJS, DTO Validation, Auth/JWT, Security.
  - `6-frontend/`: Next.js App Router, UI/UX, Tailwind CSS, BFF & API Wrapper.
